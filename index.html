iframeHunter

Ekstrak iframe video dari halaman web manapun secara otomatis

Fetch Halaman Web

Masukkan URL halaman web, tool akan mengunduh HTML-nya melalui CORS proxy lalu mengekstrak semua iframe video. Jika gagal, gunakan tab "Paste HTML" sebagai alternatif yang 100% berhasil.

Paste Kode HTML

Jika fetch URL gagal, salin kode sumber halaman (Ctrl+U di browser target) lalu tempelkan di sini. Metode ini 100% berhasil karena tidak terkena batasan CORS.

Bookmarklet Ekstraktor

Drag tombol hijau ini ke bookmark bar browser kamu. Lalu buka halaman web manapun dan klik bookmarklet tersebut untuk langsung mengekstrak semua iframe video.

Extract iFrames
Drag ke bookmark bar
Atau klik kanan > "Add to Bookmarks/Favorites"
Generator Iframe Embed

Buat kode embed iframe video dengan pengaturan yang bisa disesuaikan.
